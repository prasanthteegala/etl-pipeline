# ETL Pipeline

End-to-end ETL pipeline that ingests raw sales data from multiple 
sources, applies transformation logic, and loads into Snowflake 
data warehouse using dbt.

## Results
- Reduced data processing time by 35%
- Ingested data from 3+ sources
- Full data quality checks built in

## Tools & Technologies
- Python, SQL
- Snowflake
- dbt
- Apache Airflow
- Pandas

## Pipeline Steps
1. Extract — Load raw data from multiple CSV sources
2. Transform — Clean, deduplicate and standardise data
3. Quality Check — Validate nulls and duplicates
4. Load — Insert into Snowflake data warehouse
